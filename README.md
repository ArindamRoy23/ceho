# CEHO

![Status: in progress](https://img.shields.io/badge/status-in%20progress-yellow)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

CEHO is a persistent, speaker-aware conversational runtime. A live conversation becomes a durable, provenance-rich object: a transcript with speaker and revision history, and contextual memory built from that evidence.

The long-range product picture is in [docs/CEHO_PRD.md](docs/CEHO_PRD.md). How work is tracked, and how the functional and technical manual stays current, is in [docs/contributions.md](docs/contributions.md).

Local setup (provisional Postgres, sample env, lint and type checks) is in [docs/technical/architecture/local-development.md](docs/technical/architecture/local-development.md). The devcontainer reads [`.env`](.env) (gitignored). [`.env.example`](.env.example) is the template.
